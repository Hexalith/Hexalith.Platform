feat(pubsub/rabbitmq): opt-in mandatory publishing with correlated returns

Add publishMandatory, default false, requiring publisherConfirm. Reject
the incompatible configuration before opening a connection.

In mandatory mode register one bounded return listener per channel
generation and resolve a return after the publication's own ACK. Return
the reply code and text as a terminal FailedPrecondition error without
component retries. Match the exchange and routing key, serialize callers
through confirmation, and refuse reuse of an unresolved generation.
Application message IDs are not used for correlation.

Preserve opt-out behavior and Package A's error handling, logging, retry
limits and transport-abort ordering. Add metadata, fake-channel and native
protocol-peer coverage, plus a real-broker integration test that was
compiled but not executed locally.

Depends on #4767. Partially addresses #4765.
