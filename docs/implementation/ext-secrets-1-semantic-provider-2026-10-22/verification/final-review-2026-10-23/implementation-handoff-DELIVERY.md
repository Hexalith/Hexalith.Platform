## Delivered behavior

- `AwsAuthorityStore` reads the enrolled native table identity and a fresh strongly consistent head, verifies immutable version/hash/retention, and prewrites a complete checkpoint before one full-head CAS. Missing authority and substituted/restored table IDs fail closed. Startup never creates/enrolls/restores. Admission preserves completion reserve within the unchanged 32 MiB cap and 1,000 registration/10,000 request limits; originals/exclusions are never evicted.
- `SemanticProvider` requires exact current signed private-operation/control statements, same public enrollment and complete owner manifests. Holds require the signed durable guard dispatch-reservation protocol in [EVENTSTORE-HANDBACK.md](EVENTSTORE-HANDBACK.md). Native head CAS serializes pins, exact releases and one complete manifest reservation; earlier pins block and post-reservation pins cannot succeed. No per-target physical deletion is exposed.
- `KeyExchange` burns allocation before native execution, admits exact caller/SDK/sidecar/UDS/gRPC/TLS/component/native holders, commits a one-time send, preserves only gated key material/value-free results, and never persists a raw key response. Duplicate releases return status. Owned input/output arrays are cleared on exceptional paths; immutable protobuf, serializer, SDK, sidecar and native buffers remain registered closure obligations. Current qualified closure/transport installation is required before any release.
- Native result locators derive from the permanent tenant/intent identity before sending. Lost wrap results recover the exact immutable registration under separately current worker permission. Survivor/cut result recovery consumes signed independent exact-result evidence without resending. A genuinely lost/unverifiable result stays Unknown; no key/root/operation replacement is invented.
- The durable worker copies only survivors, stores original gated survivor sources, schedules known alternate retirement, and may abandon an uncertain successor only after independently signed permanent retirement plus producer/buffer termination. The abandoned generation is permanently tainted; recovery restores the original gated sources without native copy replay. Arm verifies closure, exact target/survivor sets and one successor adoption; source scheduling never reports erasure. B5 requires independent final deletion/copy/holder/survivor/restore evidence and a valid original P-256 signature, then merges one exact retained ordered vector into the current checkpoint.
- Inventory cannot omit registrations, original wrap bindings, enrolled source/successor/alternate generations or pre-admitted key holders already known to the checkpoint. Empty arrays plus a signed digest cannot contradict those facts. Remaining externally held copies still require installed complete-inventory and vendor/runtime assurance.
- The pinned generated Dapr component protocol, UDS/reflection host and same-profile Init remain executable. Complete protobuf sizing includes unknown fields/content type, metadata and gRPC framing; result pages remain ≤256 KiB and full responses <1 MiB. The Runtime's default path still refuses keys/oversized calls; only a freshly authorized installed transport/holder profile enables its explicit exchange seam. No production DI registration is enabled.
- Public `CustodyOwnerAuthority` supplies Dapr-only signed owner-state validation and existing four transition phases. Owner revision-zero genesis must already be independently enrolled; absent/restored local actor state never authorizes it. Owner, guard and custody-head revisions are independent. The exact current EventStore initial bytes/scope are bound and tested. Its owning checkout still needs the handback integration changes; it was not edited.
