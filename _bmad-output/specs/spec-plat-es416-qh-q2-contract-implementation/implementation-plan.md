## Identity, observations and report reconciliation

Reuse producer-defined composition/catalog/artifact/suite identities. For each new profile/configuration/test-set/inventory artifact, D2 names proposed producer roles and exact immutable UTF-8 byte rules; personal accepting names/work and actual artifact deliveries remain pending. Public configuration includes only value-free secret references/generation metadata. The fixed, ordered required-test-set artifact lists every unique required test; synthetic repeated-letter hashes identify no artifact.

The result snapshots the exact qualification scope/profile/hosts/operations/controls of the descriptor for that attempt. Advancing observations append without altering prior events, expiry, first terminal outcome or existing hold/retention/cleanup facts. Loaded evidence identifies each host/process/sidecar/cache generation; restart requires new evidence. Executing CLI identity remains separately attributable. Cross-document checking belongs to writer/evidence/consumer integration as well as shape validation.

A reached barrier binds the originally read revision, exact batch content identity, partition and host generation; release names that observation. Fresh readback references the exact adversary/batch, owning route, reader/cache generation, observed restart/cache-clear and later EventStore expected/actual logical oracle records. Bind every 3.17 inventory path to a vector/observation or demonstrated exclusion beside a lawful generic-state control. References create no new ledger, body copy or proof of freshness by themselves.

Each control request has an immutable ID and increasing event sequence. The owner reserves a use durably before mutation; identical retry reuses it without reapplying, conflicting replay refuses, unknown application retains the reservation. New requests need remaining uses and original phase/expiry admission. Validate affected host generation, partition, ordered timestamps and actual application; startup failure is never `applied`. Preserve failed reset and bounded retry. This tranche specifies validation and resource-free state-machine tests; actual control handlers and durable runtime proof remain Q4/Q5.

Bind native report processing to the exact declared suite, configuration, test-set, attempt and native test identity mapping. Reconcile individual unique required rows and required/executed/completed/passed/failed/skipped counts under the proposed D5 mapping/equations once explicitly accepted, while preserving independent existing native-report checks. No formula is applied to v1. Empty/duplicate/missing/skipped/withdrawn/incomplete required coverage or inconsistent counters refuse suite credit even with process exit zero. Preserve source SHA, actual argv, tool/artifact identities and original report/terminal references. Missing producers cannot be synthesized from exit status.

Falsification comparison metadata binds removed rule, exact profile/adversary, separate authority, intact/altered runs, passing lawful control and intended failed native prevention test. The altered terminal outcome/TRX/counts remain failed, even when the comparison demonstrates the intended missing enforcement. This tranche specifies later accounting checks using synthetic reports only; it performs neither falsification and grants no conformance/candidate credit.
