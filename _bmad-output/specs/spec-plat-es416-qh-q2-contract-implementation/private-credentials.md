## Closed file and grant tables

Use D1 I/H/T/Scope/Partition types, strict duplicate-free UTF-8 with **no BOM**, no comments/trailing commas/null, max **65,536 bytes** and **16 levels**; exactly **1–32** entries. Refuse bounded-read overflow rather than loading unbounded data. All table fields required; all objects closed. No U branch anywhere in a usable private file.

ControlGrant action `request` authorizes admitted `ControlEvent.action:apply` under D5, `observe` reads the same bound request without mutation/use consumption, and `release` releases only that admitted request. Owner reset is never a module grant.

These are recommendations for new finite kinds, not derivations from the metadata sketch. HTTP URI must be an absolute canonical `System.Uri` string with scheme/host/port and slash-terminated accepted prefix, no userinfo/query/fragment. gRPC URI uses the exact declared HTTP(S) authority with path `/`; private protocol `http` requires public endpoint protocol `http` or `https` consistent with its URI scheme; private protocol `grpc` requires public endpoint protocol `grpc`. The explicit endpoint protocol selects gRPC, not URI guessing. Resolve endpoint resource/module/name and exact URI string to the public owned resource entry and declared control/host before any client allocation. Ancestor/final links, non-regular/non-seekable/exclusively locked input, foreign workspace and private permission/ownership uncertainty refuse. Unix file mode 0600 (at most owner read/write, owner read required), parent 0700; Windows owner-only ACL verified or refuse. Stage/validate then atomic rename in the owned workspace only after successful preparation.

## Lifetime, client and reset rules

File/entry issuedAt cannot precede original accepted scope and cannot be future-dated at validation. Entry issuedAt ≥ file issuedAt; entry expiresAt ≤ file expiresAt; both strictly later than issuance. Expiry cannot exceed the earliest applicable original execution/attachment/control admission bound. A v2 qualification selection requires finite execution/stop/cleanup bounds; it does not change v1's not-declared execution branch. Use the existing whole-second native bearer expiry convention only in that separate channel; never round a private v2 access expiry later. Owner cancellation, run/attachment withdrawal, scope revocation or exact expiry ends access immediately; active requests are cancelled. Transport clients recheck scope/expiry for each send and propagate fixture disposal/cancellation. Local failure retention grants no continued module access.

Refuse redirects, proxies/cookies, caller Host/authority overrides, Basic auth, alternate Dapr target headers/metadata, caller-supplied credential headers and structurally encoded path escapes. Combine only operation-contract-approved relative segments with the exact supplied prefix; verify authority/prefix after URI resolution. gRPC interceptors enforce exact authority/service/method and no channel target override. Native bearer stays distinct on its existing channel, `APP_API_TOKEN` stays sidecar-to-application, and a Dapr API token is never reused as a native bearer/control token. If a selected protocol needs a kind outside this table, refuse pending a new reviewed design; no catch-all kind.

Control access may end before declared admission expiry. Owner reset is an **internal** exact-owner capability recorded with the existing resource/control lifecycle, not a private-file grant. It may only undo the admitted owned fault before its original reset deadline, even after module access/admission expires. It cannot admit another fault, reopen access, distribute keys, erase protected state or delete failure-retained data. Reset failure remains visible and bounded retries never extend the deadline.

Snapshot private bytes once into owner-only memory for validation and exact-value scanning; do not reopen a mutable path after inspection. Scan candidate TRX/stdout/stderr/diagnostic/archive content for every exact value **before retention**. Existing inspected-report path may redact safely; any candidate with an exact remaining value refuses retention. No raw leaking candidate, private value/file or exception enters public snapshots/logs. Delete private instance with owned workspace; server-side revocation/access termination still required even if deletion fails. No backend principal or erasure HMAC/signing key reaches module tests. Qualified OpenBao/Dapr receiver contracts, generations/rotation and purpose/partition/inventory authority remain separate blocked prerequisites, not accepted by this recommendation.
