# D2 — recommended immutable artifact byte contracts

Revision `PLAT-ES416-QH-Q2-R2`. **PROPOSED; owner acceptance pending.** These are recommended producer responsibilities and byte formats, not assignments, produced artifacts or receipts. Actual personal names, work/revisions, support/profile/test/inventory bytes and content identities are **pending**. Repeated-letter fixture digests identify none of them.

## Exact bytes

For the four new artifacts below, recommend strict UTF-8 without BOM; one compact JSON object followed by exactly one LF; no other whitespace. Members of every object are ordered by ordinal UTF-8 member-name bytes. Use lowercase literals; plain base-10 integers without sign/leading zeros (zero is `0`); forbid fractional/exponent/nonfinite values and null. Strings preserve code points without Unicode normalization, emit non-ASCII directly as UTF-8, escape only quote as `\"` and backslash as `\\`; C0/C1 controls and unpaired surrogates are forbidden. `/` is not escaped. No optional field may be omitted except where a table expressly allows it. These rules specify the **producer's bytes**, not permission for a consumer to reconstruct them.

Hash the exact original bytes, including final LF: `sha256:` + lowercase SHA-256. Consumer captures a bounded immutable byte snapshot and verifies it before parsing; never hash a reserialized descriptor or silently repair a producer's nonconforming artifact. Refuse duplicate keys, noncanonical producer encoding or reference mismatch. Public artifacts: at most 1,048,576 bytes/64 levels; individual strings use D1 I/H/S, arrays at most 4096 unless stricter below. All objects are closed, all listed fields required. Existing catalog/composition/suite/artifact identities continue to hash their existing producer-defined bytes, with no new encoding imposed on them.

No self-digest, observation, allocated URI, credential or secret value enters these four artifacts. Secret references/generation metadata are value-free. Changes to any referenced byte create a new identity/selection/attempt; consumers never rewrite the declaration to match a later report. No current release/profile is selected.

## Dependency and native-identity contract

Construct configuration, test set and complete inventory first. Profile references their hashes; none of those three contains the profile hash, avoiding a cycle. The content-bound D3 registry entry binds the four artifact identities and the original suite/manifest/entry/consumer artifact bytes. Profile purpose/support/expected and host/control templates must equal their public instantiations; component/backend/security/placement refs equal the corresponding Expected configuration identities. Run-specific Scope and actual control deadlines/observations live in the public pair, outside the profile hash. Recommend admission origin = original environment-request timestamp from the owner record; control expiresAt = the earliest of origin + admissionLimitSeconds and original applicable finite execution/attachment deadline. Reset deadline = the earlier of expiresAt + resetLimitSeconds and the original finite owner stop/cleanup end bound. Refuse missing original bounds/overflow/already-expired admission; no retry rebases origin or extends either deadline. Private entry access may end earlier under D4. This arithmetic is a proposal for owner acceptance, not a new clock or changed v1 deadline. Backend/component/config references bind value-free bytes at their existing producer boundaries; no hash of secret values, even if not disclosed.

`assemblyArtifactId` resolves to the selected expected/loaded test artifact. `assemblyFileName` is a filename without directory separators, not an arbitrary storage path. For each native TRX row, D5 joins its document-local `testId` to exactly one `TestDefinitions/UnitTest`, checks the exact assembly filename, `TestMethod.className`, `TestMethod.name`, and `UnitTest.name == UnitTestResult.testName == RequiredTest.testName`. That tuple maps to exactly one RequiredTest; `caseId` is the owner's stable discriminator recorded in the artifact, not a fuzzy runtime guess. Ambiguous adapters/cases refuse until the owner provides a new accepted mapping, never use substring, reflection discovery or generated run GUID as the stable required ID. Native GUIDs/execution IDs remain local report joins.

Before owner acceptance, supply named producer/work references and complete synthetic artifacts/full-pair closure examples in a newly hashed revision. Actual production bytes/support records remain pending until independently delivered. These proposed formats create neither an erasure authority nor a new evidence ledger.
