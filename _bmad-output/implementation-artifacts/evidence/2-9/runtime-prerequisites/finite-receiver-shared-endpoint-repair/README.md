# Shared actual endpoint inventory

The initial real Kestrel regression executed both implicit and explicit routing and refused both with HTTP403 (2/2 failed). Inspection proved separately materialized RouteEndpoint references. The repair wraps each actual root source at deferred pipeline construction so the routing matcher and finite receiver share a cached materialization; original change tokens propagate and changed references/policies never inherit admission. Capture and recapture use the wrapped app source, rather than the separate DI root composite. Original sources retain disposal ownership.

Final focused execution passed 54/54 cases, zero failures/skips/not-run, including 8 finite receiver cases (normal implicit/explicit routing, dynamic identical replacement, policy mutation, anonymous replacement, undeclared descendant, changed verb, catch-all replacement) and existing HttpHostSecurityTests. Each changed source is refused before endpoint effects and appears Admitted=false in actual receiver observation. The intermediate 1/2 failure was a test setup missing explicit UseAuthorization after explicit UseRouting; the final test retains the real authentication/authorization order. No reference-equality or policy gate was relaxed.
