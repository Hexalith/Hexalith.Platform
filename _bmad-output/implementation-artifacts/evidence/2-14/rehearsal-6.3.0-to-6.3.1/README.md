# Builds 6.3.0 → 6.3.1 adoption rehearsal (not landed)

Story 2.14 (Builds slice). This rehearsal adopts the real published Builds
[v6.3.1](https://github.com/Hexalith/Hexalith.Builds/releases/tag/v6.3.1)
(`db7bb7179244ce33483231687486381305c7c3db`) on top of the 2.14 implementation.
It ran on 2026-11-18 in a throwaway worktree that was removed afterwards. Nothing
was committed to a branch, pushed or landed.

**Base.** The rehearsal worktree started from a detached, never-pushed snapshot
of `feat/2-14-builds-version-pins` (`7a78a6c4`) plus the uncommitted 2.14
implementation. Its five pinned gitlinks were unchanged. The Builds, EventStore,
Parties, Tenants and Memories submodules were shared local clones at their
gitlinks. Only Builds moved, to the v6.3.1 commit.

## The adoption diff

[`adoption.diff`](adoption.diff) ([stat](adoption.stat)) is the complete
adoption. It contains only the three version pins, the Builds gitlink and the
regenerated lock:

| `.config/dotnet-tools.json` | tool version 6.3.0 → 6.3.1 |
| `hexalith-platform.json` | `toolVersionRange` `[6.3.0, 7.0.0-0)` → `[6.3.1, 7.0.0-0)` |

| `eng/builds-tool.lock.json` | regenerated by `python3 eng/builds_tool_lock.py` |

No C#, Python verifier, test or document changed. Builds 6.3.1 moved the generic
EventStore default from 5.2.0 to 5.3.0. The catalog view reads that default from
the gitlink catalog, so it needed no edit
([06-audit.txt](06-audit.txt) shows `genericDefaults.sdk` 5.3.0).
