# Graph export import evidence

The preprocessed MSBuild graph confirmed that the graph-export project imported
`Directory.Build.props`, `Directory.Build.targets`, and `eng/SourceRestore.props`.
It did not import the unused solution props. The
[observation](graph-export-import-observation.json) records the result.

The original 1,547,781-byte XML is preserved in Platform commit
`dc1d66b193be07e38c37014c4e6dafb97ff93af6` at this directory's
`graph-export-imports.xml` path.
